# 波段计算器 · 桌面版

**双击 `波段计算器.exe` 就能用。** 浏览器会自动打开，不需要安装任何东西。

---

## 第一次使用

1. 把 `波段计算器.exe` 存到一个固定的地方，比如桌面或「文档」文件夹
2. 双击它——Windows 可能弹出「Windows 已保护你的电脑」的蓝色提示框
3. 点「更多信息」→「仍要运行」，之后就不会再弹了
4. 浏览器自动打开，就可以用了

> 如果浏览器没有自动打开，手动在浏览器地址栏输入 `http://127.0.0.1:58380/`

---

## 数据存在哪

数据存在这台电脑的固定路径：

```
D:\SwingCalc\data.json
```

（如果电脑没有 D 盘，会自动存到 `C:\Users\<你的用户名>\Documents\SwingCalc\data.json`。以前用旧版存在这个位置的数据，第一次打开新版时会自动复制到 D 盘，原文件不删。）

只要这个文件还在，数据就还在。换浏览器、重装浏览器、清浏览器记录，都不影响。

**备份方法**：直接复制这个 `data.json` 文件到 U 盘或微信文件传输即可。

---

## 换电脑 / 迁移数据

把旧电脑的 `data.json` 复制到新电脑同样的路径就行：

```
D:\SwingCalc\data.json
```

也可以在应用里用「设置 → 导出 JSON 备份 / 导入备份文件」。

---

## 关闭程序

关掉浏览器标签页之后，任务栏右下角可能还有一个黑色命令行窗口——
直接关掉那个窗口，程序就完全退出了。

如果不想看到那个黑窗口，可以改用右键 → 以快捷方式固定到任务栏，
然后在快捷方式里勾选「最小化」窗口。

## 怎么用

### 记一笔交易

点右上角 **+**：

- **代码**：股票代码，如 `600519.SH`。持仓按它合并
- **名称**：如 `贵州茅台`，只用于显示，可以留空
- **方向**：买入 / 卖出
- **单价、数量、日期**
- **费率**：如 `0.03` 表示万分之三，默认值在设置页改

### 三个页面

- **持仓** —— 每一轮进行中的波段：持仓量、平均成本、已落袋利润
- **流水** —— 全部交易记录，可按买/卖、时间（全部 / 近1个月 / 近3个月 / 今年 / 自定义）、代码/名称搜索
- **设置** —— 默认费率、导入导出、计算方式说明

### 波段详情（买卖对照表）

在持仓页点进某一轮波段：

- 最上面四个数字：**已落袋利润、收益率、剩余持仓、持仓均价**
- 下面左边是全部**买入**，右边是全部**卖出**（窗口窄时上下排列），每行有日期、数量、单价、成交额、税费、实付/到手金额
- 每张表最后一行是**合计**：数量合计、均价（标黄）、金额合计
- 点任意一行可以修改或删除

说明：
- 买入的税费是多付的钱，所以**实付 = 成交额 + 税费**；卖出**到手 = 成交额 − 税费**
- **收益率 = 已落袋利润 ÷ 卖出那部分股票的买入成本**

### 做完一轮波段：归档

一轮波段做完了（哪怕还剩一点没卖），点进这一轮波段，拉到最下面点 **「📁 归档」**。

- 数据不会删除，在「持仓」页顶上切到 **「已归档」** 就能看到每一轮的利润和收益率
- 之后再买入同一只股票，会**从零开始算新的一轮**，不会和上一轮混在一起
- 归档错了：在「已归档」里点进那一轮，点 **「取消归档」**（如果这只股票已经开始了新一轮，就不能取消）
- 「流水」页里，已归档的交易后面会有灰色的「已归档」小标签

### 看浮动盈亏

在持仓页点进某一轮波段，填入「现价」，就会显示市值、浮动盈亏、总盈亏。

## 关于计算方式

用的是**移动加权平均成本法**，和券商 App 里「持仓成本」的口径一致。

举例：买 100 股 @ 10 元 → 卖 100 股 @ 12 元 → 再买 100 股 @ 20 元

- 本应用：落袋 **+200**（第一轮确实赚了 200）
- 简单平均法：落袋 **−300**（一笔赚钱的交易被算成亏损）

应用内「设置 → 计算方式说明」有完整对照。
