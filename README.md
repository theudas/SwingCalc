# 波段计算器（SwingCalc）

股票波段交易记账工具，给 Windows 电脑使用。

每次买入、卖出记一笔，程序会自动算出持仓均价、已落袋利润和收益率。全程不联网，数据只保存在你自己的电脑上。

## 下载与使用

1. 下载 [`releases/v1.0.0/波段计算器.exe`](releases/v1.0.0/)
2. 双击运行，浏览器会自动打开程序页面，不需要安装任何东西
3. 点右上角 **+** 记第一笔交易

详细操作请看 [使用说明](SwingCalc-桌面版/使用说明.md)。

> 用的时候不要关掉 exe 弹出的黑色窗口，关掉它程序就退出了。

## 功能

- **持仓**：每一轮进行中的波段一张卡片，显示持仓量、平均成本、已落袋利润、收益率；手动填入现价后显示浮动盈亏
- **波段详情**：买入、卖出各一张表（日期 / 数量 / 单价 / 成交额 / 税费 / 实付或到手金额），合计行显示数量和均价
- **归档**：一轮波段做完后点「归档」，之后再买同一只股票会从零开始算新一轮；以前各轮的利润在「已归档」里汇总查看
- **流水**：查看全部交易，可以按买卖方向、时间（近1个月 / 近3个月 / 今年 / 自定义）、代码或名称筛选
- **备份**：可以导出、导入 JSON 和 CSV 文件，CSV 能用 Excel 打开

## 数据存在哪

```
D:\SwingCalc\data.json
```

电脑没有 D 盘时，会改存到 `文档\SwingCalc\data.json`。备份或换电脑时，复制这个文件就可以。

## 计算方式

采用**移动加权平均成本法**，和券商 App 里「持仓成本」的算法一致：

- 买入：成交额加上税费，计入成本
- 卖出：按卖出时的持仓均价结转对应的成本，落袋利润 = 到手金额 − 结转成本
- 收益率 = 已落袋利润 ÷ 卖出那部分股票的买入成本

## 已知问题

- 设置页的「更改数据位置」暂时不要用。改过之后重启程序，会回到默认位置，看起来像数据丢了
- 归档时还没卖完的股数，不会带到新一轮

## 开发

项目结构：

```
SwingCalc-桌面版/
├── SwingCalc.html   界面和核心算法（单文件）
├── server.js        本地服务器，负责读写数据文件
├── tests/           测试
└── build.sh         打包成 Windows exe
releases/            各版本发布包
```

需要 Node.js，运行测试还需要 Python 版 Playwright。

```bash
cd SwingCalc-桌面版
npm install                # 安装打包工具 pkg
node server.js             # 本地运行（macOS 下数据写到 ~/Documents/SwingCalc/）
python3 tests/run_core.py  # 算法测试
python3 tests/ui_e2e.py    # 界面测试（用假数据，不会碰真实数据文件）
./build.sh                 # 打包，输出 dist/波段计算器.exe
```

更详细的设计说明和踩坑记录见 [HANDOFF.md](HANDOFF.md)。
