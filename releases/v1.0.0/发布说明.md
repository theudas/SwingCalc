# 波段计算器 v1.0.0

发布日期：2026-09-30

## 怎么用

把 `波段计算器.exe` 和 `使用说明.md` 发到 Windows 电脑上，双击 exe 就能用，不需要安装任何东西。详细操作见使用说明。

数据存在 `D:\SwingCalc\data.json`（没有 D 盘时存到「文档\SwingCalc\data.json」）。

## 这个版本有什么

- 记录买入、卖出，自动算持仓均价、已落袋利润、收益率（移动加权平均成本法）
- 波段详情页：左买右卖两张表，合计行显示数量和均价
- 归档：一轮波段做完后归档，之后再买同一只股票从零开始算新一轮；归档错了可以取消
- 流水页：按买卖方向、时间（全部 / 近1个月 / 近3个月 / 今年 / 自定义）、代码名称筛选
- 页面宽度跟着浏览器窗口自适应
- 导入导出 JSON / CSV 备份

## 已知问题

- 设置页「更改数据位置」暂时不要用：重启程序后会回到默认位置，看起来像数据丢了
- 归档时没卖完的股数不会带到新一轮

## 校验

`SHA256.txt` 里是 exe 的校验值。发过去后如果怀疑文件损坏，可以在 Windows 命令行里运行
`certutil -hashfile 波段计算器.exe SHA256` 对比。
